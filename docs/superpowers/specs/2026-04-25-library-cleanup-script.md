# Spec: Spotify Library Cleanup Script

**Date:** 2026-04-25  
**Status:** Approved

## Goal

A Python script that identifies Spotify library albums worth removing — albums the user will realistically never listen to. Supports configurable dry runs so different thresholds can be tested before any actual deletion happens.

## Scope

- Standalone Python script at `parser/cleanup.py`
- Works with existing `public/lastfm-data.json` (Last.fm stats)
- Uses Spotipy for Spotify library access and deletion
- No changes to the React app or existing parser pipeline

## Three Modes

```
python cleanup.py --export    # fetch Spotify library → merge with Last.fm → save cleanup_data.json
python cleanup.py --dry-run   # instant analysis using cleanup_data.json, no API calls
python cleanup.py --run       # show summary → confirm → delete from Spotify
```

## Configuration Variables

At the top of the script — the only section the user needs to touch:

```python
# ─── TUNE THESE ──────────────────────────────────────────────────────
KEEP_ADDED_WITHIN_DAYS    = 365   # albums added < N days ago → always keep
KEEP_IF_LISTEN_COUNT_GTE  = 1     # albums with ≥ N full listens (parser sessions) → keep
KEEP_IF_SCROBBLE_COVERAGE = 0.30  # rawScrobbles / trackCount ≥ this → keep (0.0 = disabled)
KEEP_IF_LAST_HEARD_DAYS   = 0     # last scrobble < N days ago → keep (0 = disabled)
# ─────────────────────────────────────────────────────────────────────
```

An album is kept if it satisfies **at least one** keep criterion. All others are candidates for removal.

`SCROBBLE_COVERAGE` is the looser alternative to the parser's strict session algorithm (50% unique tracks in one 20-min session). It checks lifetime scrobble coverage regardless of session shape.

## Keep Logic

```
KEEP if:
  (now - added_at) <= KEEP_ADDED_WITHIN_DAYS * 86400
  OR listenCount >= KEEP_IF_LISTEN_COUNT_GTE
  OR (KEEP_IF_SCROBBLE_COVERAGE > 0 AND trackCount > 0
      AND rawScrobbles / trackCount >= KEEP_IF_SCROBBLE_COVERAGE)
  OR (KEEP_IF_LAST_HEARD_DAYS > 0
      AND lastHeard AND (now - lastHeard) <= KEEP_IF_LAST_HEARD_DAYS * 86400)
```

Albums with no Last.fm match are treated as `rawScrobbles=0, listenCount=0`.

## Data Flow

### --export

1. Authenticate via Spotipy Authorization Code flow (browser opens once, token cached at `.spotipyoauthcache`)
2. Fetch all saved albums paginated from `GET /me/albums` — fields: `id`, `added_at`, `name`, `artists[0].name`, `total_tracks`
3. Load `public/lastfm-data.json`
4. Match each Spotify album to Last.fm entry via normalized key:
   - Lowercase artist + album name
   - Strip bracket suffixes: `(Deluxe Edition)`, `[Remastered 2011]`, `(DJ Mix)`, etc.
   - Key format: `"artist||album"`
5. Save merged records to `parser/cleanup_data.json`
6. Print match stats: X matched, Y unmatched

### --dry-run

1. Load `parser/cleanup_data.json`
2. Apply keep logic
3. Print summary + full removal list to stdout
4. Save output to `parser/cleanup_dry_run_YYYY-MM-DD_HH-MM.txt`

### --run

1. Load `parser/cleanup_data.json`
2. Apply keep logic
3. Show summary
4. Prompt: `"Delete N albums? Type YES to confirm:"`
5. Re-fetch current Spotify library to get fresh IDs (safety check against stale data)
6. Delete in batches of 50 via `DELETE /me/albums` (Spotify API limit)
7. Print progress and final count

## Coverage Calculation

`SCROBBLE_COVERAGE` uses `trackCount` from Last.fm data (same value the session algorithm uses — sourced from Last.fm API, MusicBrainz, or estimated). Falls back to Spotify's `total_tracks` if no Last.fm match exists. Coverage is only evaluated when `trackCount > 0`.

## Matching Notes

- Normalization strips: `(Deluxe)`, `(Deluxe Edition)`, `[Remastered YYYY]`, `(DJ Mix)`, `(Anniversary Edition)`, etc.
- Unmatched albums (no Last.fm entry) default to `rawScrobbles=0, listenCount=0, lastHeard=None`
- Match rate logged in `--export` output so user knows how many albums have no history

## Out of Scope

- Listen Later list (IndexedDB — not accessible from Python; user reviews manually)
- Artist-level filtering ("keep all albums from artist X")
- Undo / restore functionality
